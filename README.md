
# Demo Python API

A sample project for testing the Agentic AI Developer Sandbox Bootstrapper hackathon.

## Project Details
- Project Type: Python API
- Framework: Flask
- Runtime: Python 3.11+
- Environment: Development Sandbox

## Dependencies
Dependencies are listed in `requirements.txt`.

## Setup Instructions
1. Verify that Python 3.11 or later is installed.
2. Install dependencies using `pip install -r requirements.txt`.
3. Start the application using `python app.py`.
4. Check application health at `/health`.

## Sandbox Requirements
- Python 3.11+
- Permission to install project dependencies
- Network access only if required by the configured environment

## Test Data
The project uses synthetic demo data only. No production credentials or real customer data are required.

## Purpose
This repository helps test repository analysis, AI setup planning, approval workflows, sandbox creation or reuse, smoke testing, and setup manifest generation.
